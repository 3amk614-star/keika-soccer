京華高校サッカー部 スライドショー12枚版

1. ZIPを解凍。
2. index.html、background-config.js、background-admin.html をGitHubリポジトリの最上位へアップロード。
3. assets/photo-08.jpg～photo-11.jpgをGitHubのassetsフォルダにアップロード（photo-00.jpg～photo-07.jpgも同梱）。
4. Commit changes後、公開サイトをCtrl+Shift+Rで更新。
5. 変更するときはbackground-admin.htmlで12枠の写真を選択し、background-config.jsをダウンロードしてGitHubで差し替え。
※管理画面はGitHubへの自動保存機能ではありません。
※元の写真はAI加工・トリミングせず格納しています。
