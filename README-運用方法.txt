1. index.html を開くとプレビューできます。
2. 写真変更.html で3つの背景をそれぞれ選び、写真を保存。
3. ダウンロードされた concept-team.jpg / concept-football.jpg / concept-philosophy.jpg を assets フォルダに上書き。
4. index.html と assets フォルダを含むサイト一式を公開先へ再アップロード。
5. 変更が見えない場合はブラウザを再読み込みしてください。

トップのスライド写真は既存の background-admin.html を使用してください。

注意: このZIP自体は公開サイトではありません。既存のホスティング先へのアップロードが必要です。Googleフォームは閲覧者用の /viewform リンクを使用。公開設定はフォーム側で確認してください。
